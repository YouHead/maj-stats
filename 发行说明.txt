雀赛统计 0.2.9（Windows 10/11，64 位）

本版修复雀魂 WebGL 4.0.51 更新后，登录窗口停在初始黑屏的问题。
升级沿用原有牌谱和网页登录目录，无需清空缓存或删除登录信息。

使用：双击 exe 文件，无需安装 Node.js 或其他运行环境。
雀魂窗口启动时在后台加载，不抢焦点；点击“登录雀魂”才显示登录页。
首次使用在官方雀魂窗口登录，回到统计窗口填写比赛编号并点击一键导入。
支持国服普通四人麻将，其他特殊模式暂不支持。

PT：每份牌谱可展开“本场 PT”，选手表默认按 PT 降序排名，对局数位于 PT 后。
小局数放在详细信息中，不显示平均 PT。正 PT 不带加号，负 PT 保留负号并标红，Excel 同样处理。
悬停数值只显示 2/4 这样的原始计数，悬停表头显示指标定义；PT 无悬停说明。
平均打点、平均铳点、平均顺位的数值不显示悬停提示，其表头继续显示定义。
详细指标以竖线与前面的宏观指标隔开。牌谱链接和导入明细默认折叠。点击“本地牌谱记录”进入独立记录页。
记录页可按北京时间的日期范围与选手昵称或 ID 组合搜索；记录可展开详细信息。
详情包括总局数、流局数、途中流局数，以及选手顺位、终局点数、PT、立直/和牌/放铳次数。
顺位、终局点数和 PT 合并为一列。详情与选手统计表加大、加粗字体。
队伍 PT 区域恢复全宽，队名和 PT 紧凑排列，多余留白放在最右侧。
PT 与队伍上位分差统一显示一位小数，Excel 同步，原始结算数据和累计计算精度保留。
四条折线展示开局与逐小局结算点数，图表约 4:3；局次和选手点数放在右侧，字体加大加粗。
可悬停查看节点、点击图例隐藏曲线；窄窗口会自动上下排列。
“打开牌谱”直接在软件内已登录的雀魂窗口打开，复用现有登录。导入或管理记录期间暂不可打开。
此操作会在该窗口重新加载分享链接；当前版本尚未实现无需刷新页面的牌谱跳转。
关闭雀魂窗口会隐藏并保留登录；只有退出整个统计软件才结束会话。
详情使用本地缓存，不需要重新下载。删除、清空和恢复入口均在记录页。
一键导入时自动同步官方队伍名单，也可单独点击“同步队伍”。
选手昵称和 ID 下方显示队名，队伍 PT 表累计各队成员已导入牌谱的 PT。
队伍表列为序号、队伍、PT、与上位之差。序号按 PT 降序排列时编号。
与上位之差为上一名 PT 减本队 PT，第一名显示横线；Excel 使用相同规则。
队伍名单保存在当前比赛目录的 contest-teams.json，升级、重启和清空牌谱时保留。
Excel 包含选手队名和队伍 PT 表。
本场 PT 直接读取雀魂结算分 total_point / 1000，累计值只汇总已导入牌谱。
不包含赛事额外加减分或最佳若干场排名规则；缺少结算分时显示横线。

数据位置：在资源管理器地址栏输入 %LOCALAPPDATA%\MajStats
  data\contests\<比赛编号>\replays\  牌谱、选手统计和同步结果
  以上目录中的 .trash\              可恢复的删除记录
  profile\                          雀魂官方网页登录状态和网页缓存
  settings.json                     当前比赛编号
  cache\                            公开的雀魂协议资源
软件底部也可点击“打开数据目录”。Excel 导出文件通常在 Windows 下载目录。

每个 Windows 用户分别保存数据。替换、移动或删除 exe 不会删除这些记录。
删除或清空记录后可以恢复；再次同步会重新下载已删除的牌谱。
“退出登录”清除本工具的雀魂网页登录会话，已导入牌谱保留。

分享：只需发送 exe，接收者自行登录、导入。发行包不含任何已导入牌谱或登录状态。
profile 文件夹可能含 Cookie 和登录会话，属于个人数据，不要发送给他人。
若只分享统计结果，使用软件的“导出 Excel”。

升级前的开发版数据仍在原项目目录 data\ 和 .local\profile\ 中。
正式 exe 使用独立数据目录，不自动复制旧的登录状态或牌谱。
需要迁移旧记录时，先退出正式版，将开发版 data\contests\ 复制到正式版 data\contests\；请保留备份。

本发行包尚未进行代码签名，Windows 文件属性中的发布者签名显示为未签名。
只分发此目录生成的原始 exe；可用同目录 SHA256.txt 核对文件完整性。
