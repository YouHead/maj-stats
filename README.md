# 雀赛统计

Windows 桌面工具，用于导入国服雀魂普通四人麻将比赛牌谱，汇总选手表现与队伍 PT。

[下载 Windows 版](https://github.com/YouHead/maj-stats/releases/latest) · [报告问题](https://github.com/YouHead/maj-stats/issues) · [MIT 许可证](LICENSE)

## 使用

1. 从 Releases 下载 `MajStats-0.2.8-Windows-x64.exe`，双击运行，无需安装 Node.js。
2. 点击「登录雀魂」，在软件内的官方雀魂窗口登录。账号、密码与验证码只在官方页面输入。
3. 填写比赛编号并切换，点击「一键导入比赛」。也可展开牌谱链接输入区，粘贴一条或多条官方分享链接。
4. 查看选手统计和队伍 PT，按指标排序，或导出 Excel。在「本地牌谱记录」中按日期、昵称或账号 ID 搜索，展开对局详情。

同一牌谱按 UUID 去重，不同选手视角不会重复计数。导入支持停止、重试和增量补齐；只有读取到列表末页且全部牌谱成功统计，才显示完成。每个比赛分别存储，导入时核对牌谱归属。是否能读取某场比赛取决于当前账号在官方客户端中的访问权限。

官方窗口默认静音，启动时在后台加载并恢复会话；会话过期时需重新登录。详情中的「打开牌谱」复用软件内的登录窗口，但会重新加载官方分享页面。目前尚未实现无刷新跳转。

## 功能

- 选手表默认按 PT 排名，支持一至四位率、平均顺位及详细指标切换；选手名与表头固定，支持指标排序及计数提示。
- 详细指标包括小局数、和牌率、放铳率、自摸率、默胡率、流局率、流听率、副露率、立直率、平均打点、平均铳点、和了巡数。
- 自动读取官方队伍名单，汇总队伍 PT 与上位分差。名单查询失败时保留上次完整结果。
- 对局详情显示总局数、流局数、顺位、终局点数、PT、立直/和牌/放铳次数，以及可查看节点与切换曲线的点数折线图。
- 记录支持单条删除、清空当前比赛与恢复；再次同步会补齐已删除的官方记录。
- Excel 导出包含「选手统计」「队伍 PT」「原始计数」「统计口径」「逐场 PT」，保留数值精度并提供筛选、冻结列与百分比格式。

PT 直接取牌谱结算的 `total_point / 1000`，先累计原始整数再换算，显示一位小数。队伍 PT 为已导入队员 PT 之和。统计只涵盖本机已导入牌谱，不含赛事额外修正分、晋级分或最佳若干场规则，因此可能与官方榜单不同。缺少必要数据时显示横线，不填成零。

## 统计口径

| 指标 | 定义 |
| --- | --- |
| 一至四位率 | 对应顺位次数 / 对局数；顺位按最终点数，同点按起始座位顺序 |
| 和牌率 | 和牌小局数 / 参与小局数 |
| 放铳率 | 放铳小局数 / 参与小局数；一炮多响仍只计一局 |
| 自摸率 | 自摸次数 / 和牌次数 |
| 默胡率 | 门清且未立直的和牌次数 / 和牌次数，包含门清自摸；暗杠不破门清 |
| 副露率 | 有吃、碰或大明杠的小局数 / 参与小局数；暗杠不计 |
| 立直率 | 立直宣言小局数 / 参与小局数，包含宣言牌被荣和 |
| 流局率 | 荒牌流局次数 / 参与小局数；途中流局单列，流局满贯仍按荒牌事件计数 |
| 流听率 | 荒牌时听牌次数 / 荒牌流局次数 |
| 平均打点 | 优先采用 `dadian`，缺失时取荣和点或自摸支付合计，再对和牌取平均 |
| 平均铳点 | 放铳实际支付合计 / 放铳小局数，包含本场、不含供托；多响合并计点 |
| 和了巡数 | 和牌时全桌累计舍牌数 / 4 + 1，再对和牌次数取平均 |

参与小局数包含连庄、荒牌及途中流局；跨牌谱先累计计数再计算比例。自摸支付及其他人的包牌支付不计放铳；抢杠归到杠牌者。分母为零或必要明细不全时留空。

当前支持普通四人麻将。三麻、血战、开局公开手牌等特殊规则会报错，不输出可能失真的部分统计。

## 数据与登录信息

正式版保存到 `%LOCALAPPDATA%\MajStats\`，可点击软件底部「打开数据目录」。不同 Windows 用户分别保存；替换 exe 不会清空记录。

| 位置 | 内容 |
| --- | --- |
| `data/contests/<比赛编号>/replays/` | 原始牌谱、派生统计、队伍名单与同步结果 |
| 上述目录中的 `.trash/` | 可恢复的删除记录 |
| `profile/` | 官方雀魂网页登录状态及网页缓存，可能包含 Cookie、Local Storage 等会话信息 |
| `settings.json` | 当前比赛编号 |
| `cache/` | 官方公开协议资源 |
| `runtime.json` | 当前本地服务地址 |

分享软件只需发送 exe，可附使用说明与校验文件。接收者自行登录、导入。不要分享 `profile/` 或整个数据目录；分享统计结果可使用 Excel。退出登录清除官方网页会话，已导入的牌谱保留。本工具不另存明文密码。

本地界面服务只监听 `127.0.0.1`。本工具向雀魂官方读取比赛与牌谱，没有统计数据上传服务。发行包尚未进行代码签名，可用同版 `SHA256.txt` 核对文件完整性。

## 开发与构建

使用 Node.js 24、npm；桌面运行与打包面向 Windows 10/11 x64。Windows 构建还需要 PowerShell 7（`pwsh`，用于生成图标）。

```powershell
npm ci
npm run electron:install
npm run protocol:refresh
npm test
npm start
```

`electron:install` 下载锁定版本的 Electron 桌面运行时；`protocol:refresh` 从雀魂官方公开资源取得协议定义，不需要登录。启动或构建时若没有协议缓存，也会自动获取。官方协议变更可能影响兼容性，可以重新刷新协议后重试。

```powershell
npm run dist:win
npm run test:package
```

产物位于 `dist/`。打包白名单只允许应用代码、生产依赖、许可文件和两份公开协议 JSON；真实牌谱、网页登录配置及导出文件不会进入发行包。构建会核对 ASAR 内源码及许可文件与当前版本一致，并生成 SHA-256。

`test:package` 实际隐藏运行 exe，在 `.cache/tests/` 的隔离目录验证首次启动、持久化、合成牌谱、Excel、删除/清空/恢复及用户目录隔离，不读取日常登录配置。构建与运行检查分别写入 `dist/package-verification.json` 和 `dist/smoke-verification.json`。

开发版的数据位于项目内 `data/`、`.local/profile/`、`.local/settings.json` 和 `.cache/`，均不提交到 Git。迁移到正式版时先退出软件，将 `data/contests/` 复制到正式版相应目录并保留备份；登录信息不会自动迁移。

测试全部使用合成牌谱，不需要账号、真实选手名单或私人样本。协议首次下载需要网络。更多贡献说明见 [CONTRIBUTING.md](CONTRIBUTING.md)。
